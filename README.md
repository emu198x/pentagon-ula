# pentagon-ula

The Pentagon 128's uncontended ULA.

| Crate | Registry |
|---|---|
| [`emu198x-pentagon-ula`](crates/emu198x-pentagon-ula) | [crates.io](https://crates.io/crates/emu198x-pentagon-ula) |

Part of [Emu198x](https://github.com/emu198x/emu198x), a family of
cycle-accurate retro-computing emulators. Used by the Pentagon 128.

Each crate is versioned on its own and bumps only when it changes. Releases go
through release-plz: merging its release pull request tags the crate and
publishes it.
